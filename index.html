relicwise
relicwise is a fan project and isn't affiliated with HoYoverse. Game data: StarRailRes · build data: Fribbels HSR Optimizer (MIT) · profiles: Enka.Network

Settings

Enka.Network and the warp-history API don't allow direct browser requests, so relicwise sends them through a small proxy you deploy for free (see worker/ in the repo). Leave it empty when running locally with python3 tools/dev_server.py.

Stored in this browser

Profiles, warp history and scanned relics are saved only in this browser (localStorage).
